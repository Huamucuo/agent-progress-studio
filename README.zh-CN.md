# Agent Progress Studio — Windows 桌面版

[English](README.md) · <!-- APS_VERSION -->0.3.0-desktop.1<!-- /APS_VERSION --> · MIT

本机 AI 编程任务监控软件。打开独立窗口，选择具体 Work/Codex 会话，查看实际活动、最近工具、已验证工作与待处理事项。此候选版等待独立来源、安全和打包审计，尚未公开发布。

## 安装和打开

- **安装版：**运行 `AgentProgressStudio-0.3.0-desktop.1-Setup.exe`，选择个人目录，再从桌面或开始菜单打开。
- **便携版：**完整解压 `AgentProgressStudio-0.3.0-desktop.1-Portable.zip`，双击 `AgentProgressStudio.exe`。保留全部配套资源及 DLL。
- 最终用户**无需浏览器、Node.js、npm、命令行或手动启动本地服务**。Electron 自带运行时。候选包尚未签名，请用交付 SHA256 核对。

[安装、连接、暂停、托盘、开机启动、日志与卸载说明](docs/desktop/USER-GUIDE.md)。

## 首屏如何理解

选择数据源，再从名称/编号列表选择任务；完整 ID 放在高级信息中。首屏显示当前在监控谁、最近观测到什么、最近工具、已验证条件和待处理条件。采集通道可用不等于 Agent 正在执行；Stop 只说明回合停止，不能证明项目完成。没有新事件时继续观察：已知未结束的工具显示等待对应结果，其他旧证据无法确认此刻是否仍在执行。

原生浮窗支持拖动、缩放、小条、隐藏与恢复。拖到屏幕任一边缘松开即可吸附：平时只显示 2 × 24 DIP 短小贴边提示，鼠标接近才显出 28 × 44 DIP 小 APS 标签（左右边缘），单击 APS 即展开向内侧拉的面板，无需拖拽；离开后缩回。原生窗口区域裁掉的部分既不显示也不挡住鼠标。悬停宽度不会保存为下次启动状态。固定位置、置顶和固定展开分别控制。贴边标签平时完全透明、不可见并穿透鼠标，真实露出下层桌面；鼠标靠近时 50% 可见，点击展开后 100% 可见；旧版透明度设置不会覆盖这三档行为。消息紧贴侧栏可见区域，随移动、收缩、小标签和展开跟随；旧固定角落设置不再让消息脱离侧栏。托盘和 Ctrl+Alt+Shift+A 可恢复浮窗。展开后上方为仪表盘，下方为消息和受控回复框。仅展示已经授权的 Codex 公开消息，Work 无消息/回复接口时明确不可用；新消息更新不会重置输入草稿。确定性中英文解释区分观察事实和系统推断，无需付费模型或 API。

三种度量分别计算：没有可靠剩余工作模型时，**总体进度未知**；计划进度是 Agent 报告的完成/总步骤；验收通过率根据明确条件和权重。工具调用次数不参与完成比例。缺少任务、计划、Token、上下文和时间数据时保持未知，不编造预计完成时间。

## 连接 Work 或 Codex

可选“桌宠”默认关闭。开启后可独立显示四种像素动物，支持六种多帧状态、拖动、大小、固定、置顶、隐藏和托盘恢复。透明空白区域穿透鼠标；隐藏停止动画。状态仅来自当前授权事实，过时或未知时待机。等级/本地金币、五项可用商店和 PNG 包导入均不影响任务进度或关机判断。[桌宠使用与本地存档](docs/desktop/DESKTOP_PETS.md) · [美术来源/许可](docs/PET_RESOURCE_LICENSES.md)。

首次引导检查连接。Work 使用自愿安装的**仅元数据 Hook 适配器**；需在原生确认框明确勾选授权，应用才通过官方本地插件命令安装。信任需在客户端另行完成。“已安装”“已信任”“已观测到活动”分别处理。收到真实回调后发现新会话，保留已选择目标；逐会话确认 Work/Codex 来源，不能确认时未知。原有独立探针可通过目录选择器连接。

四个基础字段为 event_type、session_id、turn_id、timestamp；工具事件另有 tool_name、tool_status，共六字段。不持久保存提示词、完整聊天、工具参数/输出或隐藏推理。此 Work 接口不提供完整计划、任务文本、Token、上下文或 Git 工作目录，显示未知。合成测试不等于真实宿主兼容性验证。[协议及历史宿主实验](docs/WORK-HOOKS.md)。

Codex 发现只读文件名 UUID。指定旧会话即使超出最近的候选列表，也会单独按文件名定位并保留；最多检查 10,000 个条目，重复 UUID、来源已确认 Work 或核实不完整时保持不可用，且不读取正文。确认某个后端/ID 属于 Codex 并明确授权，才读取该会话正文，正常退出后记住授权。Git、测试和实现证据需要单独工作区授权。Work/未知正文默认拒绝。高级信息保留官方本机 app-server 监控及能力协商下的 ID-only 发现。侧栏回复有**独立、默认关闭的权限**，只适用于已授权且由官方本地控制接口加载的 Codex 任务；不恢复会话、不改变模型、沙箱或审批。Work 回复不可用。[完整权限边界](docs/PRIVACY-SCOPE.md)。

当前真实宿主验证：用户指定并明确授权的旧 Codex 任务已在原生主窗口和浮窗显示。实验桌面 Hook 的五项定义已信任，但新事件目录收到的**真实回调仍为 0**，不能认定 Work 连接成功。宿主官方本地控制套接字不可连接，因此真实侧栏送达和无人值守关机尚未验证。合成桌面/打包测试在交接中另列。

## 桌面关闭流程和隐私

浮窗 × 默认隐藏，可设置隐藏后是否继续监控。主窗口关闭时，若浮窗仍显示或已开启托盘后台则隐藏，否则退出。明确点击“退出”会停止采集并完成权限持久化。暂停清空 UI 和旧订阅；恢复创建新权限实例并保留选定会话。开机启动默认关闭。重复启动同一数据配置会激活已有窗口。错误时安全暂停，可重开窗口、查看固定代码日志或退出。

每日自动清理仅处理本应用的 Chromium 缓存并提示结果；自有 Hook 文件最多保留 8,000 个事件，不清理独立探针或聊天。“自动关机”默认检查**当前来源中已接入且授权的全部任务**；首次开启需原生授权，之后凭工作执行结束、官方空闲及无后台执行的最新证据，经过稳定等待和可取消倒计时，结束后不再询问。未知后台状态会阻止关机；静默、Stop 或验收比例都不足以触发。开关不跨重启保存，也不涵盖未接入的软件或云任务。

渲染进程没有 Node 权限。界面通过安全的应用专用来源加载，采用沙箱、上下文隔离和受控 IPC。原有统一授权网关覆盖读取、证据、缓存及最终发送/导出。桌面路径**不启动 HTTP/SSE 服务**。本应用 Hook 通过带随机凭据的本地 Windows 命名管道提交元数据，落盘绑定当前观察代次；退出或撤销后旧记录器不能继续写。独立探针由其自己管理。应用不上传聊天、源码或日志。[桌面架构](docs/desktop/IMPLEMENTATION.md)。

报告通过原生保存窗口导出当前已授权 JSON；撤销会清除实时数据并拒绝迟到内容。已经保存的报告由用户自己保管。卸载/移动应用前，先在设置移除本应用 Hook 并关闭开机启动；卸载保留专用用户数据，用户自行决定清理。

## 验收与证据

在获授权工作区提供 `.agent-progress/acceptance.json`，参考[原创示例](fixtures/acceptance.example.json)和[证据格式](docs/EVIDENCE.md)。可定义实现文件、命名测试、权重和人工确认。保留 Git 差异/提交、测试结果、文件证据及持久化人工备注；证据变化会让旧确认失效。支持中英文、深浅主题。演示明确标注模拟，可重播、暂停和单步。
