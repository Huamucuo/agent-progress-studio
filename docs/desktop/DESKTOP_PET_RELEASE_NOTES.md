# Agent Progress Studio 0.3.0-desktop.1

2026-10-14。Windows x64 本地候选；未公开发布，等待 Work B 独立审计和人工验收。

本轮新增默认关闭的桌宠与养成：四种温暖像素动物，各六种四帧状态；独立透明窗口、点击抚摸、拖动/大小/固定/置顶、托盘显示隐藏、位置恢复。五项小商店与本地 XP/金币真实保存，PNG 资源包先审阅来源与许可再导入。原有实时监控、三种进度、智能解释、证据、消息侧栏和安全关机模块保留。

修复启用后重启的初始空白、活动过时仍工作、快速拖动丢失末位移、新画风配件偏移。主动隐藏释放宠物窗口；重新显示重新取得当前授权，旧快照不能恢复。未知/断线时待机，不把 Stop 或宠物等级当作任务成功。所有动画可关闭；低性能选项减少绘制。没有新增生产依赖、模型 API、云同步或私人读取权限。

实际当前 Codex 已观察到工具开始/返回并联动宠物；Work 本轮真实 Hook 回调仍为零，未宣称连接成功。Work 的计划、正文、Token、回复和可靠后台空闲不由元数据适配器提供。官方控制连接不可用时，侧栏回复与无人值守关机保持不可用/等待。

最终便携与安装测试通过受控接口、合成会话和真实原生窗口进行；这不代替真实 Work、物理多屏/DPI、拖动/托盘/快捷键、交互安装或纯净虚拟机验收。用户按 Esc 中断后停止了物理鼠标自动操作。自动关机始终 dry-run。
