## 用户可见增量

- 默认关闭的独立透明桌宠窗口：四种像素动物、六种状态、每状态四帧、抚摸/拖动/大小/固定/置顶/隐藏/托盘恢复/位置保存。
- 本地等级、XP、金币、成长记录、五项真实购买/装备/动作、PNG 包许可预览与导入/移除。
- 新旧官方 APS 插件状态查询、信任事件名称规范化、已安装自有插件目录连接。安装和信任不冒充真实事件成功。
- 所有既有监控、侧栏、回复权限、缓存、证据与自动关机仍由原模块管理；桌宠没有额外正文权限。

## 模块与边界

desktop/pet-controller.mjs 只消费 DesktopHost 当前 Publication 的授权快照；src/pet/state.mjs 产生没有标题、正文、路径或会话 ID 的最小宠物投影。主、浮、宠三窗口共享原 SessionAccess。desktop/host.mjs 保留原不透明凭证，最终输出仍按原代次检查，不能通过去掉传输依赖来刷新旧授权。

宠物角色没有 snapshot、monitor、sessions、detail、export、来源/授权变更、回复、Hook 安装或关机能力。preload 只提供命名操作，WindowRegistry 按角色和导航代次拒绝。主进程限制形状消息、图片并发和数据大小；协议只注册固定本地资源，不开放文件路径。没有新增网络连接、HTTP/SSE 或生产依赖。

src/pet/progression.mjs 使用原子存档、独占完整租约和持久 HMAC 去重。新事实在排队前、异步边界和最终提交前检查原授权。撤销/重新授权/切换/暂停丢弃旧事实；启动基线、DEMO、Stop 和工具次数无成功奖励。验收去重不随证据版本、来源或人工升级重置。上限停止奖励而不是淘汰历史键。

src/pet/pack.mjs 在正文打开前仅根据目录项和属性拒绝日志、未知文件、子目录、别名与链接。PNG 检查大小、类型、精确块名、CRC、哈希和有界解压；预览确认绑定原文件身份/完整清单，导入原子安装。移除先原子禁用，部分删除不使其他包失效。新增读入口限应用宠物存储和用户主动选择的 PNG 包，不读取会话来分类。

desktop/managed-spool.mjs 只接受官方本地插件清单中可核验的 APS 所有权、五项精确命令和目录；不扫描别的插件内容，不改全局配置。Hook 事件仍为四基础/六工具字段。连接按钮通过正常 selectSource 授予现有观察范围，随机管道凭据绑定当前代次。其他活跃实例拥有目录时拒绝争抢。

## 开发内审查发现及修复

1. 启用桌宠后的重启：原初始化先于 IPC 注册，导致首次设置请求丢失。新增“真实形状+非空像素”重启回归先失败，随后将初始化移到 IPC 注册之后通过。
2. 活动过时：权限心跳不能替代工具活动。增加 30 秒活动时效和可见窗口看门机制；关闭动画也检查，隐藏停止计时。实际渲染器内存测试覆盖有心跳无快照 45 秒和完全失联 11 秒。
3. 快速拖动：首个 32ms 轮询前结束的拖动丢失最后位移。新增先失败的单元用例，dragEnd 先同步采样并应用最终位置再保存。修复后的物理拖动验收未完成，保留 MANUAL_TEST_REQUIRED。
4. 测试等待：Playwright 1.56 的 waitForFunction 立即检查返回值，异步谓词可因 Promise 为真提前完成。改为测试进程逐次 await 的有界轮询，并增加永假谓词不能通过的回归。覆盖 pet、floating、edge、packaged 相关等待，未放宽生产条件。
5. 前期模块审查还修复钱包租约完整发布、PNG 块高位字节别名、移除中断/残留配额及导入确认竞争边界。对应回归随源码提供。
6. 新画风配件挂点按当前绘制头部对齐；睡眠时收起帽子与围巾。主动隐藏销毁宠物窗口，恢复使用新渲染器和当前授权；隐藏启动不分配该窗口，以减少后台内存。原进程、位置及养成存档不受删除操作影响。

## 验证性质与限制

完整自动回归、浏览器与包检查见 Audit 的逐项记录；统计只说明相应用例结果，不证明产品完工、许可或安全认证。新 PetController→真实钱包集成覆盖启动历史、DEMO、Stop、有效回合、防重复、验收变化、撤权/重新授权/迟到消息以及 Work 元数据零正文读取。

当前已授权的真实 Codex 对话在原生新版本中持续观察约 77 秒，收到 12 条新增事件，显示工具执行/返回及宠物工作/待机。该对话计划为零、整体进度 null，未发送测试消息，未导出私人正文。发布证据只包含去身份化状态摘要，私人截图和测试配置不进入交付。

官方桌面插件已安装、启用，五项定义已信任，但本轮实际工具测试的当前 Hook 目录仍为 0 条回调。故 Work locally 真正连接及新 Work 自动发现仍为 NOT_VERIFIED / MANUAL_TEST_REQUIRED，不能用合成 Hook 回归或当前 Codex JSONL 结果代替。官方控制套接字不可用，真实回复送达、可靠后台空闲与无人值守关机仍受阻。没有关闭 Windows，没有私有接口替代。

真实 Windows 鼠标已确认宠物透明空白处穿透至自有背景，本体点击触发开心互动且未落入背景。随后计算机控制被用户 Esc 中断，已停止鼠标操作；拖动、菜单、托盘恢复、最终包的物理四边点击、多显示器和 125/200% DPI 留待人工验收。不要将自动设置窗口坐标当成真实拖动。
