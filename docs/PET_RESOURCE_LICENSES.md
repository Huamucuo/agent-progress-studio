## 内置像素美术来源

依据用户最新反馈，角色改为温暖的 16-bit 治愈系像素美术，保持动物特征、清晰表情与有限暖色。早期 SVG 样稿与上一轮拟真候选均已替换，不作为本次完成素材发行。公开参考、选择理由与推断边界见 [PET_STYLE_RESEARCH.md](PET_STYLE_RESEARCH.md)。
四份原始 1024×1536 RGBA PNG 图集由内置图像生成工具制作。首只犬从文字生成，其他物种仅使用该自制犬图集作为风格和排列参考，没有下载、描摹或使用第三方角色图片、GIF、素材包、字体。制作工具仅用于开发期；应用运行不需要网络模型服务。
生成提示全文见 [pet-prompts](pet-prompts/)。不采用第三方 IP 名字或已知形象；线描犬为象牙色、灰色拼斑和炭色轮廓的原创幼犬方案。带彩色边缘或风格不符的生成候选未纳入源码/发行包。

作者记录：Agent Progress Studio contributors，AI 辅助制作。项目意图按根目录 MIT 许可提供新增代码和自制内置资源。该记录不认证著作权、独创性或第三方权利，仍待 Work B 来源/许可审查及用户美术验收。

## 本地渲染与资源边界

原始生成图集另存于随交付提供的 ArtSources 资源归档，原件哈希记录在 docs/pet-art-originals.json；原件字节不改动。发行包使用每格 128×128、整图 512×768 的透明紧凑 PNG（上表是发行资源哈希）。可用 scripts/compile-pet-art.mjs --source-dir <解压后的原始图集绝对目录> 从原件重建；这是本地构建流程，不调用模型或上传文件。public/pet-assets.mjs 只能选择四个固定本地路径，不能插入用户文本、URL 或脚本。
构建时以 128×128 逻辑像素网格最近邻取样，去除低透明度背景噪点及断开的相邻格残片，保留的轮廓像素设为不透明；主体重心和脚底锚点稳定，避免图格漂移。构建结果逐帧验证无裁切和二值透明边缘。运行时直接读取紧凑帧，不重复分割，不改写原件；放大不平滑插值，周围实际 alpha=0。
帽子、围巾、宠物垫由本项目像素绘制代码提供；帽子与围巾按当前帧绘制头部位置对齐，睡眠时收起配件，宠物垫仍保留。铜色犬使用固定毛色规则，招手用抬前肢帧；不使用 Emoji 或外部角色资源。
缓存至多一份约 1.5 MiB 的解码图集、十二个 128 像素准备帧，窗口另有六帧小缓存。隐藏停止动画定时器；关闭动画使用固定帧；低性能模式降低频率。无音效，不阻止休眠，无云同步或真实支付。
资源绘制检查、真实 Windows 原生操作和真实 Work/Codex 事件必须分别记录。DEMO、合成事件和人工动作展示不算宿主监控成功。

## 用户资源包 schema 1

首版导入用户主动选择的普通目录。该目录只能包含 `manifest.json` 以及清单中的 PNG，不能有子目录、额外文件、大小写别名、链接、代码或远程资源。
来源和受控存储路径拒绝 UNC 网络路径、Windows 设备路径及远程 URI；本功能不建立下载或网络连接。
打开任何 manifest 或 PNG 正文之前，先只枚举名称并检查文件类型、链接数及大小，拒绝 `.jsonl`、`.log`、其他未知扩展名、子目录、大小写不符和链接。资源目录选择不授予会话正文读取权限，也不会读取目录中的日志来推测它是否安全。
测试用含 `SYNTHETIC_PRIVATE` 清单及合成 rollout UUID `.jsonl` 的目录验证：检查和导入均拒绝，实际文件打开调用数为零；其他未知文件、大小写异常、子目录及链接同样在正文打开前拒绝。
先调用 `inspectDirectory(source)` 完整验证并返回作者、来源、许可等信息供确认；随后 `importDirectory(source,{expectedManifest: inspectedManifest})` 重新验证后原子安装。
管理器私下保留有限数量的预览身份快照；传入确认后的清单时，必须存在同一路径的先前预览，来源目录、每个文件身份、完整清单摘要以及帧哈希均与该次预览一致。许可、ID、内容或文件替换后需要重新预览及确认。
预览不安装资源，预览成功不能代替后续导入验证。主进程的原生选择与确认流程应始终传入 `expectedManifest`；省略该参数的底层接口仅进行完整资源校验，不应作为界面的确认流程。

```json
{
  "schema": 1,
  "id": "user-my-pet",
  "name": "我的本地宠物",
  "version": "1.0.0",
  "author": "实际素材作者",
  "source": "本地制作方式与来源说明",
  "license": "完整许可说明或可核实的许可全文链接",
  "canvas": {
    "width": 256,
    "height": 256,
    "anchor": { "x": 128, "y": 208 },
    "slots": {
      "hat": { "x": 128, "y": 56 },
      "scarf": { "x": 128, "y": 146 },
      "action": { "x": 174, "y": 166 },
      "background": { "x": 128, "y": 210 }
    }
  },
  "files": [{ "file": "frame.png", "sha256": "填写实际文件的64位小写SHA256" }],
  "states": {
    "idle": [{ "file": "frame.png", "duration": 250 }],
    "working": [{ "file": "frame.png", "duration": 250 }],
    "waiting": [{ "file": "frame.png", "duration": 250 }],
    "happy": [{ "file": "frame.png", "duration": 250 }],
    "failed": [{ "file": "frame.png", "duration": 250 }],
    "sleeping": [{ "file": "frame.png", "duration": 250 }]
  }
}
```

此结构示例使用同一帧演示格式，不是实际动画成品，也不是可直接导入的素材；哈希必须换成实际值。六状态均必需，帧可以共享同一文件；推荐提供有明确语义的真实动画帧。`slots` 可以为空对象，挂点仅接受已知四种坐标；`anchor` 为画布内坐标。

边界与配额：

- 包 ID 为 3–64 位小写字母/数字/连字符，首位字母；保留全部 `aps-` 内置 ID。
- PNG 名称最长 64 位，仅小写 ASCII、数字、下划线、点、连字符；拒绝 `..`、Windows 保留设备名、绝对路径、分隔符、ADS 和 URL。
- 六状态累计最多 96 帧，最多 96 个图像文件；每帧声明时长为 16–10000 毫秒，界面可以再限制实际绘制速度。
- 图像单文件最多 2 MiB、包总字节最多 20 MiB、manifest 最多 64 KiB；安装目录最多 32 个用户包。
- 画布每边最多 512 像素，图像尺寸必须一致；仅支持 8-bit 非交错灰度/RGB/灰度加透明度/RGBA PNG。
- 每个 PNG 校验签名、IHDR、全部块 CRC、IDAT、IEND、SHA256、精确解压大小以及过滤行；拒绝调色板 PNG、元数据、APNG 和其他块。该有限子集是明确兼容边界，不代表全部 PNG 格式受支持。
- 文件读前后检查目录身份、句柄与名称的文件身份、大小、时间和硬链接数；拒绝符号链接、目录别名及重解析路径。成功导入只复制已经验证的资源字节，不执行包内任何内容。
- 安装用独立暂存目录与原子目录重命名；失败暂存不会注册为宠物。崩溃残留暂存目录不启用，不自动递归删除陌生目录。
- 32 个包的配额只统计启用命名空间，禁用的 `.remove` / `.import` 残留不影响有效包启动。禁用残留达到 64 个时暂停新增导入，等待受控清理；原有有效包仍可读取。32 个有效包加卸载残留的重启边界已单独测试。
- 运行时 `asset(id,file)` 只接受已注册 ID/文件名，重新检查内容和身份，返回 `{bytes,mimeType:'image/png',sha256,width,height}`；不向渲染器提供文件路径。
- 卸载先原子重命名已注册目录至 `.remove-UUID` 禁用命名空间，随后只清理已知 PNG/JSON 文件。删除中断或磁盘拒绝只能留下禁用残留，不会使其他有效包在下次启动时不可用。不会移除内置绘制程序、用户原始导入目录或宠物成长数据。

所有来源、许可与作者信息均为导入者提供的声明。它们不等于 APS 对第三方权利的保证；是否可随公开发行版本再分发仍需独立审查。测试中的微型 PNG 由代码合成，仅用于安全测试，不作为宠物预览素材。
