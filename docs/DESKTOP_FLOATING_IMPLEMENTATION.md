Architecture constraints: one DesktopHost and original Publication/SessionAccess authority for all content. Floating payload is a reduced projection sealed with the original permits; final IPC write rechecks the original authority. Only registered own main frames may request; float does not gain content grants, native file picker or configuration installation methods. Navigation clears that window's subscriptions, while authorization changes invalidate every window. No HTTP listener or remote scripts. Window geometry/preferences contain no session body.
